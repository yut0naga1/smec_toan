# 中小企業診断士原稿用紙メーカー

中小企業診断士2次試験の再現答案を貼り付けると、1行20マスの原稿用紙に1マスずつ書いた形で Word（.docx）・PDF を出力する静的サイト。

## 使い方

`index.html` をブラウザで開く（サーバー不要・外部ライブラリなし・入力は外部送信しない）。

- 全角1文字＝1マス。半角英数字は1マスに2文字。
- 行頭に来る句読点（、。，．）は前の行の20マス目に同居させる。閉じ括弧も同様に扱うオプションあり。
- `#` で始まる行は設問見出し。`# 第1問 100字` のように字数を書くと、その字数分のマス目を用意し超過を警告する。
- 100字ごとに右端へ目盛り（100, 200, …）を付ける。

## ファイル

- `index.html` — 画面とプレビュー
- `genkou.js` — マス割り付けと .docx / .pdf 生成
  - docx: 無圧縮ZIPを自前で組み立て
  - pdf: 非埋め込みの標準日本語フォント（HeiseiMin-W3 / HeiseiKakuGo-W5, UniJIS-UCS2-H）。1文字ずつ座標指定するため代替フォントでもマスがずれない
- `test/genkou.test.js` — `node --test test/genkou.test.js`
